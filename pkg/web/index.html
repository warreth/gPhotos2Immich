    Connect a Google account

    Open the Google sign-in page

    Open sign-in
    2

    Approve and copy the cookie

    Click "I agree". The page may keep loading, that is expected. Then open DevTools, go to Application or Storage, Cookies, accounts.google.com, and copy the value of oauth_token.

    3

    Paste and connect

    The token is sent to the local server and stored in a private file. It is never shown again.
    This credential has full access to the Google account. Consider a dedicated account and keep the data directory private.

    Connect a browser session

    One-time setup, about a minute.

    1

    Open Google Photos

    Sign in with the same account you connected above.

    Open Google Photos
    2

    Export the cookies

    Use a cookies.txt extension for this site. Export the cookies for photos.google.com and keep the file private.

    3

    Paste and connect

    Stored in the data directory with mode 0600. The value is never shown again.
    This session can read and change your Google Photos library. Use it only on a machine you trust, and disconnect when you no longer need shared-album uploads.

    Upload settings

    Applies to every album unless the album overrides it.

    Unlimited storage is off by default. It makes the uploader identify as a Pixel phone, so Google does not charge your quota. This is unofficial and can change at any time; use at your own risk.
    Keep this at 1 unless uploads feel slow. Higher values are more likely to hit Google rate limits.

    Connect one Immich user to one Google Photos account.

    Loads from Immich when the connection works.
    Used when the Immich user list cannot be loaded.
    The account that uploads this person's photos to Google Photos.
    Needed only if you want Google to Immich albums imported under this person's Immich account. Immich assigns the asset to the API key owner.
    How to get the Google oauth_token
    1. Open Google Embedded Setup and sign in as this person.
    2. Click "I agree". The page may keep loading, that is expected. Then open DevTools, Application or Storage, Cookies, accounts.google.com.
    3. Copy the oauth_token value and paste it below. The token is stored in a private file and never shown again.
    Shared albums that someone else owns need a signed-in photos.google.com session. Stored with mode 0600.
